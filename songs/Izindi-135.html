#135

Es-tu lavé dans le sang?

Izindi

Couplet 1

As-tu rencontré Jésus qui purifie? es-tu lavé dans le Sang de l’Agneau? As-tu pleinement confiance en Sa Grâce maintenant? Es-tu lavé dans le Sang de l’Agneau?

Refrain

Es-tu lavé dans le Sang de l’Agneau qui purifie les âmes? Tes habits sont-ils purs aussi blancs que neige? Es-tu lavé dans le Sang de l’Agneau?

Couplet 2

Marches-tu chaque jour à côté du Sauveur? Es-tu lavé dans le Sang de l’Agneau? Demeures-tu chaque jour dans le Crucifié? Es-tu lavé dans le Sang de l’Agneau?

Refrain

Es-tu lavé dans le Sang de l’Agneau qui purifie les âmes? Tes habits sont-ils purs aussi blancs que neige? Es-tu lavé dans le Sang de l’Agneau?

Couplet 3

Quand l’Époux viendra, ta robe sera-t-elle blanche? Pure et blanche dans le Sang de l’Agneau? Ton âme sera-t-elle prête pour le beau palais? Es-tu lavé dans le Sang de l’Agneau?

Refrain

Es-tu lavé dans le Sang de l’Agneau qui purifie les âmes? Tes habits sont-ils purs aussi blancs que neige? Es-tu lavé dans le Sang de l’Agneau?

Couplet 4

Débarasse-toi de ces habits de péché; Et sois lavé dans le Sang de l’Agneau! Il y a une Fontaine qui coule pour l’âme impure. Oh! sois lavé dans le Sang de l’Agneau!

Refrain

Es-tu lavé dans le Sang de l’Agneau qui purifie les âmes? Tes habits sont-ils purs aussi blancs que neige? Es-tu lavé dans le Sang de l’Agneau?
