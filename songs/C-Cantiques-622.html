Je serai quelque part

Coll. des Cantiques

Couplet 1

Lorsque le Sauveur m’appellera, J’entendrai et je répondrai; Lorsqu’Il appelle, je répondrai, Je serai quelque Part pour entendre mon nom.

Refrain

{Je serai quelque Part, je serai Quelque part, Quelque Part-là pour entendre mon nom.} x2

Couplet 2

Si mon cœur est droit quand Il m’appelle, Si mon cœur est droit, j’entendrai; Si mon cœur est droit quand Il m’appelle, Je serai quelque Part pour entendre mon nom.

Refrain

{Je serai quelque Part, je serai Quelque part, Quelque Part-là pour entendre mon nom.} x2

Couplet 3

Si ma Robe est blanche quand Il m’appelle, Si ma Robe est blanche, j’entendrai; Si ma Robe est blanche quand Il m’appelle, Je serai quelque Part pour entendre mon nom.

Refrain

{Je serai quelque Part, je serai Quelque part, Quelque Part-là pour entendre mon nom.} x2
