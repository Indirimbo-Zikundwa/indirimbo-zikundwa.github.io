#193

Le Christ devoile

Crois Seulement

Couplet 1

Notre béni Christ de beauté Etait voilé aux humains; Mais par souffrances, chagrin et mort, Voile, en deux, Il déchira.

Refrain

Oh! regardez l’homme de chagrin! Regardez-Le dévoilé, Oh! Il est le puissant Conquérant, Dès qu’Il déchira le voile, Oh! Il est le puissant Conquérant, Comme Il déchira le voile.

Couplet 2

Oui, Il est avec Dieu, le Père, Là, intercédant pour vous; Car Il est le puissant Vainqueur, Comme Il déchira le voile.

Refrain

Oh! regardez l’homme de chagrin! Regardez-Le dévoilé, Oh! Il est le puissant Conquérant, Dès qu’Il déchira le voile, Oh! Il est le puissant Conquérant, Comme Il déchira le voile.

Couplet 3

Saints anges s’inclinent devant Lui, Les hommes de la terre Le louent; Car Il est le cher Bien-aimé, Comme Il déchira le voile.

Refrain

Oh! regardez l’homme de chagrin! Regardez-Le dévoilé, Oh! Il est le puissant Conquérant, Dès qu’Il déchira le voile, Oh! Il est le puissant Conquérant, Comme Il déchira le voile.

Couplet 4

Dans le temps, les âges sans fin, Il est le seul donateur Du grand et profond vrai amour, Comme Il déchira le voile.

Refrain

Oh! regardez l’homme de chagrin! Regardez-Le dévoilé, Oh! Il est le puissant Conquérant, Dès qu’Il déchira le voile, Oh! Il est le puissant Conquérant, Comme Il déchira le voile.
