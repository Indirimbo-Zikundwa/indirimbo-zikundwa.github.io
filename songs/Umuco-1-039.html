#39

Mwami wacu Yesu turagusaba

Umuco 1

Couplet 1

Mwami wacu Yesu turagusaba, Twebw’abana bawe ngw utwumvirize, Ico tugusaba n’udufashe, Mwami hagarikira Igikorwa cawe.

Refrain

Mwami Yesu n’utwumvirize, Turagusavye ng’udufashe, Mwami hagarikira igikorwa cawe.

Couplet 2

Rab’abana bawe aho turi, Mw’isi y’umwijima n’udufashe, N’udukangure twame turi maso, Mwami hagarikira igikorwa cawe.

Refrain

Mwami Yesu n’utwumvirize, Turagusavye ng’udufashe, Mwami hagarikira igikorwa cawe.

Couplet 3

Rab’isi yose yahagurutse, Kugwany’igikorwa cawe Mwami, None n’udufashe twikangure, Mwami hagarikira igikorwa cawe.

Refrain

Mwami Yesu n’utwumvirize, Turagusavye ng’udufashe, Mwami hagarikira igikorwa cawe.

Couplet 4

Raba abansi b’umusaraba, Badukikuje ngo batugwanye, None tugusaba ng’udufashe, Mwami hagarikira igikorwa cawe.

Refrain

Mwami Yesu n’utwumvirize, Turagusavye ng’udufashe, Mwami hagarikira igikorwa cawe.

Couplet 5

Turagusaba ng’udufashe, Kuko twebw’abantu ntaco dufise, Ico tugusaba duhe kwitanga, Mwami hagarikira igikorwa cawe.

Refrain

Mwami Yesu n’utwumvirize, Turagusavye ng’udufashe, Mwami hagarikira igikorwa cawe.
