#130

Je sais ce qu’est le sang

Izindi

Couplet 1

{Je sais ce qu’est le Sang} x2 Pour moi: {Lorsque j’étais perdu, à la Croix Il mourut; Je sais, ce qu’est le Sang pour moi.} x2

Couplet 2

{Et Son Sang est la Vie} x2 Pour moi: {Tous mes péchés lavés, Le Salut est acquis; Et Son Sang est la Vie pour moi.} x2

Couplet 3

{Si Christ n’était pas mort} x2 Pour moi, {Je serais toujours errant et n’ayant point la Vie; Si Christ n’était pas mort pour moi.} x2

Couplet 4

{L’amour de Dieu pour moi} x2 est si grand. {Depuis l’éternité l’Agneau fut immolé; L’Amour de Dieu est si grand pour moi.} x2

Couplet 5

{Je suis heureux pour Christ} x2 Sauveur. {De ce qu’Il m’a aimé et m’a donné Sa Vie; Je suis heureux pour Christ Sauveur.] x2

Couplet 6

{Je chante pour Jésus,} x2 Sauveur. {Tous les jours de ma vie, je chante Alléluia! Pour le Sang versé à la Croix.} x2

Couplet 7

{Il reviendra Bientôt} x2 Pour moi; {Il a préparé la place pour Son Épouse; Il reviendra bientôt pour moi.} x2
