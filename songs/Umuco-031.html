#31

Mwami wanje ndakwihaye ndakwihereje

Umuco

Couplet 1

Mwami wanje ndakwihaye ndakwihereje, nizeye y’uk’utazigera umpemuki-ra, warapfuye urazuka non’uri Muzima, ./.N’undinde mu ngendo zose ziy’isi Mwami./.

Refrain

Mwami ndakwihereje n’Undongore ukugomba, wiyerekane mu Rusengero rwawe, name nuzuy’amazi ./.y’isoko idakama./.

Couplet 2

Mwami wanje ndakwihaye ndakwihereje, ndaguhay’Ubugingo bwanj’ubwiganzire, unyuzuze rwa Rukundo rwawe Mukiza ./.Nkund’abandi nk’uko nanje wankunze./.

Refrain

Mwami ndakwihereje n’Undongore ukugomba, wiyerekane mu Rusengero rwawe, name nuzuy’amazi ./.y’isoko idakama./.

Couplet 3

Mwami wanje ndakwihaye ndakwihereje, name ngendera mu nyonga zawe Mukiza, unyuzuze za mbabazi zaw’Uhoraho ./.Mparir’abandi nk’uko wampariye, Mwami./.

Refrain

Mwami ndakwihereje n’Undongore ukugomba, wiyerekane mu Rusengero rwawe, name nuzuy’amazi ./.y’isoko idakama./.

Couplet 4

Kandi Mwami ninashika kuri rwa ruzi, uz’umpe gutinyuka nuzur’ukwizera, ndarujabuke nuzuy’inkomezi zawe ./.Nzama ndirimb’ Urukundo rw’Imana./.

Refrain

Mwami ndakwihereje n’Undongore ukugomba, wiyerekane mu Rusengero rwawe, name nuzuy’amazi ./.y’isoko idakama./.

Couplet 5

Ninarenguka mu nyonga z’Umwami Imana, nta kindi nzirata Atari wa musaraba, nzomushimisha rwa Rukundo rwiwe rwinshi, ./.Tumushime n’abiwe iyo mw’Ijuru./.

Refrain

Mwami ndakwihereje n’Undongore ukugomba, wiyerekane mu Rusengero rwawe, name nuzuy’amazi ./.y’isoko idakama./.
