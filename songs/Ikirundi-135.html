#135

Mbega ko Yesu Yatanz’ Amaraso yiwe ku Musaraba

Ikirundi

Couplet 1

Mbega ko Yesu Yatanz’Amaraso yiwe ku Musaraba, ko Yatanz’ Ubugingo bgiwe Agukure mu vyaha vyawe.

Refrain

None se mugenzi uzomuh’ iki Uwo Mucunguzi, Yatanz’ Amaraso ng’ukizw’ ivyaha, none s’uzomuh’iki?

Couplet 2

Har’aho wigeze kwibaz’ ivyiza vyose biri mw’Ijuru? Womeny’ ivyo Yesu Yasize mw’Ijuru mu kuz’ aha mw’isi?

Refrain

None se mugenzi uzomuh’ iki Uwo Mucunguzi, Yatanz’ Amaraso ng’ukizw’ ivyaha, none s’uzomuh’iki?

Couplet 3

Uraz’imibabaro Yesu yagiz’ ari ku Musaraba? Uko bamutey’ icumu Akav’ Amaraso bo n’amazi?

Refrain

None se mugenzi uzomuh’ iki Uwo Mucunguzi, Yatanz’ Amaraso ng’ukizw’ ivyaha, none s’uzomuh’iki?

Couplet 4

Womeny’ Urukundo rw’ akaburarugero Yes’Agukunda? Uraz’ urugero rw’ Imbabazi ziwe n’ikigongwe ciwe?

Refrain

None se mugenzi uzomuh’ iki Uwo Mucunguzi, Yatanz’ Amaraso ng’ukizw’ ivyaha, none s’uzomuh’iki?
