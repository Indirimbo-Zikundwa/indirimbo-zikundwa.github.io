a. JE SUIS PELERIN ÉTRANGER

Izindi

Couplet 1

Je suis pèlerin étranger, errant dans ce monde pécheur, sur ma route vers la Cité, lorsque les Saints entreront.

Refrain

Quand les Saints entreront, lorsque les Saints entreront, Seigneur, je veux être de ce nombre; Lorsque les Saints entreront.

Couplet 2

Je sais je verrai mon Sauveur si ma vie est libérée, le Ciel m’ouvrira ses portes, lorsque les Saints entreront.

Refrain

Quand les Saints entreront, lorsque les Saints entreront, Seigneur, je veux être de ce nombre; Lorsque les Saints entreront.

Couplet 3

Lorsqu’assemblés autour du Trône et les portes sont fermées, Je crierai: « Gloire! Gloire! » Lorsque les Saints entreront.

Refrain

Quand les Saints entreront, lorsque les Saints entreront, Seigneur, je veux être de ce nombre; Lorsque les Saints entreront.

Couplet 4

J’attends que le Chariot descend et je monterai au bord, sur les nuées j’irai au Ciel, lorsque les Saints entreront.

Refrain

Quand les Saints entreront, lorsque les Saints entreront, Seigneur, je veux être de ce nombre; Lorsque les Saints entreront.
